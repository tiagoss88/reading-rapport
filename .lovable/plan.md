# Limpar cache para atualizar o sistema

## Ação

1. Abrir o preview em uma sessão automatizada.
2. Remover os caches da aplicação e registros antigos do service worker de navegação.
3. Limpar o armazenamento local e de sessão do navegador.
4. Preservar o banco de dados e os arquivos do projeto.
5. Reabrir o sistema na versão atual e confirmar a tela carregada.

## Observação

A sessão de login poderá ser encerrada e será necessário entrar novamente. O worker exclusivo de notificações não será removido permanentemente.
